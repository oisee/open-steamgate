## One click

[Start with the defaults](command:osd.quickStart) builds and runs the system, then opens **System overview** with the live port, database, layers, warm state, and routes.

The defaults are SQLite, the ABAP keymap, and warm activation in `auto` mode. On a host with at least 4 GB of memory, warm activation is enabled; the running system reports its actual state.

Open the [OSD view](command:workbench.view.extension.osd) at any time. Its first row opens the same System overview.
