<a id="kernel-bit-and-operand-not-x"></a>
### BIT-AND on non-byte operands

SAP requires byte operands (x or xstring), rather than integers, for bit operations.

Rejected by SAP:

```abap
DATA value TYPE i.
value = value BIT-AND value.
```

```abap
DATA bytes TYPE x LENGTH 2.
bytes = '1234'.
bytes = bytes BIT-AND bytes.
```

<a id="kernel-xstring-offset-write"></a>
### Offset/length write on xstring

SAP rejects writes into an xstring offset/length slice, including MOVE, CLEAR and CHANGING targets.

Rejected by SAP:

```abap
DATA local TYPE xstring.
local = '1234'.
local+0(1) = '05'.
```

Read into a fixed-length x field, change its slice, then assign it back to the xstring. Match the x length to the bytes being edited; this example edits a two-byte value.

Correct rewrite:

```abap
DATA bytes TYPE x LENGTH 2.
DATA local TYPE xstring.
local = '1234'.
bytes = local+0(2).
bytes+0(1) = '05'.
local = bytes.
```
